# Steps to run this program

+ Download
+ cd dsstatus
+ npm install && npm run dev

# Decisions
+ added search in addition to brief requirements, felt appropriate
+ used actual html table for table as it's preferrable for landmarks/accessibility
+ abstracted out buttons to their own component due to UI heaviness
+ abstracted out header for potential re-use if there's expansion on the theme
+ fa icons for visual indicators, with color, but the word is right there so no additional signifiers needed
+ focus indicators
+ hover highlighting of table rows
+ long backstory available on request for color choices
